# 🤖 Telegram Mention Bot
# بوت منشن للتيليجرام

بوت تيليجرام لعمل منشن (Mention) لأعضاء المجموعة - 5 أعضاء في كل رسالة.

## ✨ المميزات

- ✅ منشن لجميع الأعضاء المسجلين
- ✅ تقسيم المنشن إلى مجموعات من 5 لتجنب السبام
- ✅ نظام تسجيل طوعي للأعضاء
- ✅ دعم المستخدمين بدون username
- ✅ واجهة عربية سهلة الاستخدام

## 📋 الأوامر

| الأمر | الوصف |
|-------|--------|
| `/start` | بدء البوت وعرض الترحيب |
| `/help` | عرض المساعدة |
| `/addme` | إضافة نفسك لقائمة المنشن |
| `/removeme` | حذف نفسك من قائمة المنشن |
| `/list` | عرض قائمة الأعضاء المسجلين |
| `/mention` | منشن لجميع الأعضاء (5 في كل رسالة) |

## 🚀 التثبيت

### 1. إنشاء البوت

1. افتح تيليجرام وابحث عن `@BotFather`
2. أرسل `/newbot`
3. اتبع التعليمات واختر اسم للبوت
4. احفظ الـ Token الذي ستحصل عليه

### 2. إعداد المشروع

```bash
# استنساخ أو تنزيل المشروع
cd telegram-mention-bot

# إنشاء بيئة افتراضية (اختياري)
python -m venv venv
venv\Scripts\activate  # Windows
# source venv/bin/activate  # Linux/Mac

# تثبيت المتطلبات
pip install -r requirements.txt
```

### 3. إعداد التوكن

```bash
# انسخ ملف المثال
copy .env.example .env

# افتح الملف وأضف التوكن
# BOT_TOKEN=your_actual_token_here
```

### 4. تشغيل البوت

```bash
python bot.py
```

## 📱 كيفية الاستخدام

1. أضف البوت للمجموعة
2. امنح البوت صلاحيات الأدمن (ليتمكن من إرسال الرسائل)
3. اطلب من الأعضاء التسجيل باستخدام `/addme`
4. استخدم `/mention` لعمل منشن للجميع

## ⚠️ ملاحظات
